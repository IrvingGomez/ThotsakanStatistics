# 2026-10-28 — Demo mode for public events

For the event on 6 November, the app can run as a login-free public demo, separate from the instance students sign in to.

- `DEMO_MODE=true` skips sign-in without Google credentials. `/api/auth/config` reports `"demo": true` and the logo bar shows a neutral "Demo" badge instead of the amber "Auth disabled (dev)" one.
- Uploads larger than `MAX_UPLOAD_MB` (10 in demo mode, 100 otherwise) are refused with HTTP 413 and a message.
- `SESSION_MEMORY_MB` (1024 in demo mode, unlimited otherwise) caps the memory of all open datasets together; the least recently used are dropped first.
- nginx limits `/api/data/upload` per client IP (`UPLOAD_RATE_LIMIT`, default `120r/m`, burst 60, then 429) on every deployment; `client_max_body_size` comes from `CLIENT_MAX_BODY_SIZE` (default `100m`).
- `.env.demo.example` starts the demo as its own compose project on port 8081; `.env.*` files are now git-ignored except the examples.

Tests: `backend/tests/api/test_auth.py` (demo config, no credentials needed, env defaults), `backend/tests/api/test_upload.py` (413, eviction), `frontend/src/layout/LogoBar.test.tsx` (badge). Decision recorded in `docs/decisions.md`.
