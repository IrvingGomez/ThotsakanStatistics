# Code of Conduct

Thotsakan Statistics is an educational project for Thai engineering students. Students, teaching staff and contributors all use it, so we hold ourselves to a standard that fits a learning environment.

## Our Pledge

We want participation to be harassment-free and welcoming for everyone, whatever their age, body size, disability, ethnicity, gender identity or expression, level of experience, nationality, appearance, race, religion, or sexual identity and orientation.

## Our Standards

**Behavior we expect**

- Be respectful and patient. Many contributors are students and are still learning statistics, Python or TypeScript.
- Give feedback on the work, not the person. Explain *why* a change is needed and suggest a fix.
- Accept feedback graciously. The professor's verification of `core/` math is part of the process, not an obstacle.
- Credit others' ideas, code and data sources.
- Communicate in English or Thai, and be inclusive of both. Don't mock anyone's language proficiency.

**Behavior we do not accept**

- Harassment, insults, discrimination, or personal or political attacks.
- Public or private harassment, or publishing others' private information without consent.
- Sexualized language or imagery, or unwelcome advances.
- Trolling, or sustained disruption of discussions and reviews.
- Academic dishonesty, such as presenting statistical output as verified when it is not, or copying code without respecting its license.

## Scientific and Academic Integrity

This project teaches statistics, so correctness is a conduct issue and not only a quality issue.

- **Never fabricate results.** Test expectations, reference values and documentation examples must come from a trusted source (scipy, statsmodels, pingouin, a textbook, or a hand derivation). Cite it.
- **Be honest about limits.** If an approximation or a provisional preview is shown (for example `provisional: true` in `frontend/src/math/`), label it clearly. Never present it as authoritative.
- **Report errors openly.** If you find a math bug, report it. Don't hide or quietly patch it.
- **Student data is private.** Uploaded datasets live in memory only, keyed by session ID with a TTL. Never log, commit, or share real student or personal data. Use synthetic or public data in tests and examples.

## Scope

This Code of Conduct applies in all project spaces: the repository, issues, pull requests, code review, commit messages, and any channel where someone represents the project. It also applies to AI coding agents working on the repository (see [`AGENT.md`](AGENT.md)). People are responsible for the output of agents they run.

## Enforcement

Maintainers are responsible for clarifying and enforcing these standards. They may remove, edit, or reject comments, commits, code, issues and other contributions that don't follow this Code of Conduct, and may temporarily or permanently ban contributors for behavior they judge inappropriate.

Report violations privately to the project maintainers or the supervising instructor. All reports will be reviewed promptly and confidentially. Maintainers will respect the privacy and safety of the reporter.

Typical consequences, in increasing severity:

1. **Correction:** a private or public request to change the behavior, with an explanation.
2. **Warning:** a formal warning, with a period of no interaction.
3. **Temporary ban:** removal from project spaces for a set period.
4. **Permanent ban:** for sustained or serious violations.
